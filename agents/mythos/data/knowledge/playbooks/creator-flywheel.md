# Mythos creator flywheel — adapted from @XCreators / @Ethan_Ng_13 Grok Bot guide

Local creator playbook for Mythos. Busywork off the owner’s plate; owner keeps creative judgment and final publish.

## Flywheel
Learn → inspiration → ideas → script → record → edit → distribute → analyze → repeat.

## Know the owner
- Brain-dump style, past videos, loved references, analytics.
- Context turns a generic agent into a second creator brain.

## Inspiration → ideas
- Curated feeds; break down why it worked, hook, pacing, sound, make-it-yours.
- Store lessons in Mythos prefs / knowledge — not a cloud Notion dependency.

## Script coach (not ghostwriter-first)
- Score hooks, pacing, open loops, voice match.
- Prefer coaching the owner’s draft over replacing their voice.

## Produce with human-in-the-loop
1. Train on editing style until Mythos can explain it back.
2. Ingest raw footage / assets locally.
3. Propose an editing plan.
4. Owner approves or corrects.
5. Execute edit (local tools / scripts).
6. Review with proof.
7. Prepare distribution; owner presses send unless autonomy says otherwise.

## Parallel creation
- Batch jobs where scripts can run; do not burn the LLM on work a script can do.

## Every video teaches the next
- Retention drops → hypothesis → next script lesson logged as improvement.

## Money and risk
- Prepare posts; owner confirms publish/send/spend unless explicitly delegated.
